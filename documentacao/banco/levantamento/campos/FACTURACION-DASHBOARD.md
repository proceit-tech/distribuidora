## Regras confirmadas no código

1. **Estado da factura** — valores exatos: `BORRADOR`, `EMITIDA`, `APROBADA`, `RECHAZADA`, `ANULADA` (`types/facturas.ts:1-6`). A emissão grava sempre `APROBADA` (`facturas-storage.ts:208`). Nenhuma outra transição existe no código.
2. **Condición de operación** — `CONTADO`, `CREDITO` (`types/facturas.ts:8-10`; `nuevo/page.tsx:573-578`).
3. **Tipo de transacción** — `VENTA_MERCADERIA`, `PRESTACION_SERVICIO`, `MIXTO`, `MUESTRAS_MEDICAS`, `DONACION`, `OTRO` (`types/facturas.ts:12-18`).
4. **Indicador de presencia** — `PRESENCIAL`, `INTERNET`, `TELEFONO`, `OTRO` (`types/facturas.ts:20-24`).
5. **Moneda** — `PYG`, `USD`, `BRL`, `EUR` (`types/facturas.ts:26-30`); PYG formata sem decimais com prefixo `Gs.`, as demais com 2 decimais (`page.tsx:26-46`).
6. **Medio de pago** — `EFECTIVO`, `TARJETA`, `TRANSFERENCIA`, `CHEQUE`, `OTRO` (`types/facturas.ts:62-67`).
7. **Receptor** — `naturaleza`: `CONTRIBUYENTE`/`NO_CONTRIBUYENTE`; `tipoContribuyente`: `PERSONA_JURIDICA`/`PERSONA_FISICA` (`types/facturas.ts:35-36`). Ao selecionar cliente, a factura recebe uma CÓPIA (snapshot) dos dados e `numeroCasa` = `"0"` (`nuevo/page.tsx:222-259`); o snapshot continua editável.
8. **Item** — `afectacionIva`: `GRAVADO`/`EXENTO`; `porcentajeIva`: `0`, `5` ou `10` (`types/facturas.ts:53-54`). `subtotal = cantidad × precioUnitario` sem arredondamento (`nuevo/page.tsx:343-350`).
9. **Numeração interna** — `FAC-` + número com `padStart(6,"0")`; próximo = maior sequência numérica existente + 1 (`facturas-storage.ts:142-164`). Ex.: `FAC-000001` (`lib/mocks/facturas.ts:8`).
10. **Numeração do documento** — formato exibido `sucursal-punto-secuencia` = `001-001-0000001`: 3 dígitos / 3 dígitos / 7 dígitos (`page.tsx:305-309`; `[id]/page.tsx:107-111`; `padStart(3)` no punto e `padStart(7)` na sequência em `facturas-storage.ts:210`). Sequência automática = maior `Number(numeroSecuencia)` + 1 com `padStart(7,"0")`, calculada sobre TODAS as facturas, sem separar por empresa, sucursal ou punto de expedición (`facturas-storage.ts:166-183`). Opções de punto: `001`, `002`; sucursal: `001` (`nuevo/page.tsx:490,520-525`).
11. **CDC gerado (demo)** — `01800033140001` + punto(3) + secuencia(7) + `AAAAMMDD` + `12345678901` (`facturas-storage.ts:209-210`); mensagem `Documento aprobado`. É simulação, não cálculo SIFEN.
12. **Cálculo de totais** (`calcularTotalesFactura`, `facturas-storage.ts:36-93`): classificação por item — `EXENTO` ou `%=0` → exento; `%=5` → subtotal5; demais → subtotal10. O preço já inclui o IVA: `baseGravada5 = round(subtotal5/1,05)`, `baseGravada10 = round(subtotal10/1,10)` (somente se subtotal > 0), `iva = subtotal − baseGravada` (o IVA é o resto, logo base + IVA = subtotal), `totalIva = iva5 + iva10`, `totalBaseGravadaIva = base5 + base10`, `totalOperacion = totalGeneral = exento + subtotal5 + subtotal10`, `liquidacionIvaX = ivaX`. Arredondamento: `Math.round` do JavaScript (meio para cima), a inteiro, sem considerar a moeda. Conferência com o mock: 85.000/1,05 = 80.952 (IVA 4.048); 72.000/1,10 = 65.455 (IVA 6.545); total 157.000, total IVA 10.593 (`lib/mocks/facturas.ts:92-105`).
13. **Validações de emissão** — apenas: cliente selecionado (`clienteId` não vazio) e ao menos 1 item (`nuevo/page.tsx:381-397`).
14. **Forma de pago em CONTADO** — `monto` acompanha `totalGeneral` ao adicionar/editar itens (`nuevo/page.tsx:316-323,363-372`).
15. **Adição de produto** — `afectacionIva` = `EXENTO` se %=0; quantidade inicial 1; unidade = `unidadMedidaNombre || "Unidad"` (`nuevo/page.tsx:275-302`).
