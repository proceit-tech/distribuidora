# Nexit V1 — Investigação de dados apontada pela auditoria de listagens (CON-03, 04, 05, 09)

**Data:** 2026-10-11 · **Resultado:** nenhum defeito de código encontrado; os três primeiros pontos dependem do dado carregado (origem da carga, fora do repositório). **Nada foi alterado em regras de negócio, dados ou banco.**

| ID | Verificação no código/modelo | Conclusão | Ação sugerida (precisa de autorização) |
|---|---|---|---|
| CON-03 Código de inventário | `productos.codigo_inventario` é `text` (NEX-007); API e tela gravam e exibem o texto sem converter para número (`lib/productos/shared.ts`, apenas `trim` e limite de 80). Zeros à esquerda NÃO se perdem na aplicação. | Se um código aparece sem os zeros esperados (ex.: `026102469668`), o valor já chegou assim ao banco — típico de planilha Excel que trata o código como número na carga. | Confrontar o código no banco com a planilha de origem; se divergir, corrigir a carga/dado (caso a caso, com aprovação) e importar a coluna como texto. |
| CON-04 Procedência × Categoria | Procedência é o texto livre `productos.origen_etiqueta`; Categoria é FK para `categorias_producto`. A aplicação não relaciona nem converte uma coisa na outra. | `FRANCIA` (procedência do produto) e `FRANCESA` (nome de uma categoria) são dados distintos; a categoria `FRANCESA` parece ter sido carregada a partir da coluna de origem. O produto exibido não tem categoria associada. | Decidir com o piloto se origem deve ser categoria; em caso afirmativo, ajustar a carga/associação (dado), não o código. |
| CON-05 Código em Catálogos | `categorias_producto.codigo` (e das demais tabelas de catálogo) é `text` NULL permitido por modelo; o formulário trata código como opcional. | Código ausente é válido. A lista agora mostra "Sin código" (texto discreto) em vez de `—`. | Nenhuma, salvo decisão de tornar o código obrigatório (mudança de regra). |
| CON-09 Sobrestock | `lib/stock/shared.ts`: `SOBRESTOCK` quando `stock_maximo > 0` e existência física propia (disponible + reservado + cuarentena) > máximo; igual ao relatório Stock general. O Stock crítico usa a mesma regra (disponível + reservado/cuarentena). | Regra coerente entre listagem e relatórios. Um produto aparece como Sobrestock apenas porque o `stock_maximo` cadastrado é menor que a existência (ex.: máximo muito baixo herdado da carga). | Revisar o `stock_maximo` do produto afetado na ficha; se o valor for placeholder da carga, corrigir o dado. A tela agora exibe a definição de Sobrestock e a legenda R/C/T. |
